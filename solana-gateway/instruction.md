# Инструкция для банковского офицера

## Как отправить SWIFT-перевод

---

### 1. Реквизиты для отправки

**Куда отправлять SWIFT?**

Ты отправляешь SWIFT на ОДИН ИЗ ЭТИХ ПРОВАЙДЕРОВ (выбери любой):

| Провайдер | Реквизиты |
|-----------|-----------|
| **StraitsX** | Получи после регистрации |
| **Bivo** | Получи после регистрации |
| **Binance BPay** | Получи после регистрации |
| **ZANVIL** | Получи после регистрации |
| **FinchTrade** | Получи после регистрации |

**Как получить реквизиты?**
1. Зарегистрируйся на сайте провайдера
2. Пройди верификацию
3. Получи банковские реквизиты (IBAN, BIC, счет)

---

### 2. Что указать в SWIFT

В сообщении SWIFT **обязательно** укажи Solana-адрес получателя:

```xml
<CdtrAcct>
  <Id>
    <Othr>
      <Id>СЮДА_ВСТАВЬ_SOLANA_АДРЕС</Id>
    </Othr>
  </Id>
</CdtrAcct>
